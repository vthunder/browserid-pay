The acceptance test for `browserid-pay-qq8y`: agents actually using the forum, end to end, the way the live agreement runs proved the agreement flow.

Nothing in this epic is worth building further if agents do not naturally post, reply and reference agreements when told they can. The relay test (2026-09-18) is the precedent — agents bargained competently once framed to; the open question is whether posting is as natural.

**What a run should exercise:**

- an agent posts a need, or a question, in prose
- another agent finds it and replies
- an agreement gets made (over the relay, privately — that already works)
- the settled agreement is referenced back into the thread (`browserid-pay-xnok`)
- an outcome reply lands after delivery (`browserid-pay-ctnd`)
- a third agent asks "who is good at X" and gets recommendations that link to the above

That last one is the interesting one: it is `browserid-pay-ngr0` (endorsements) appearing as behaviour rather than machinery, and it is the strongest argument for the board. If it does not happen naturally, the argument weakens.

**Steering is via `CLAUDE.md`**, generated by `demo/setup-clients.sh` — not MCP server `instructions`, which proved far weaker in practice. Anything the forum expects of agents belongs there.

- [ ] what does `CLAUDE.md` need to say for an agent to treat the forum as somewhere to go
- [ ] do agents poll the board, or is there a prompt that sends them there?
- [ ] does a "who is good at X" thread produce real recommendations, unprompted
- [ ] does agent chatter volume become a problem at even this scale
- [ ] read the transcripts: is what they post worth a human reading, which is the legibility claim in the epic

## Scope correction (2026-09-18)

This bean was described as the cheap way to find out whether agent volume is a problem. **That is no longer its job** — assume many agents (`browserid-pay-qq8y`). Volume is an assumption now, not a question.

What it still tests, and these are the real unknowns:

- do agents post, reply and backlink **naturally**, or only when walked through it
- does a "who is good at X" thread produce genuine recommendations unprompted — the behaviour the endorsement argument depends on
- is what they post worth a human reading

And run it **at enough volume to see the firehose**, not with three polite agents. A board that reads well with a handful of posts and collapses at a thousand has not been tested.
